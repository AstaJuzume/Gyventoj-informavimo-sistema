# Gyventojų informavimo sistemos prototipas

Statinis demonstracinis prototipas, paruoštas publikuoti su „GitHub Pages“.

## Publikavimas

1. Išarchyvuokite ZIP failą.
2. Visus jame esančius failus įkelkite į GitHub repozitorijos pagrindinį katalogą.
3. GitHub repozitorijoje pasirinkite **Settings → Pages**.
4. Skiltyje **Build and deployment** pasirinkite **Deploy from a branch**.
5. Pasirinkite šaką **main**, katalogą **/(root)** ir paspauskite **Save**.

Duomenys išsaugomi naudotojo naršyklėje (`localStorage`). SMS ir el. laiškai realiai nesiunčiami. Serverio ir duomenų bazės šiam demonstraciniam paketui nereikia.
